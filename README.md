# PR screenshots

This branch stores only screenshots shown in pull requests: one folder per PR number (`113/leaderboard.png`). It has no
code and is never merged. PR descriptions and comments link the images as
`https://github.com/kolabs-dev/isim/blob/screenshots/<PR>/<name>.png?raw=true`, so files here are never deleted or
renamed (that would break the PRs that show them). See AGENTS.md, "Screenshots".
